## 可重复执行的检查

在项目根目录，使用已初始化的开发虚拟环境：

```powershell
# --noconftest 很重要：避免加载现有业务测试的自动清理数据库 fixture。
.\.venv\Scripts\python.exe scripts/run_tests.py --noconftest tests/test_docker_init.py -q --basetemp=.runtime/pytest-docker-unit
# 此脚本不连接数据库；若没有 Compose，会明确报告相关检查跳过。
.\.venv\Scripts\python.exe scripts/test_docker_deployment.py
# 只检查 Docker 前置环境，不创建部署密钥或启动服务。
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/docker_deploy.ps1 -CheckOnly
```

容器完整验收应在具备 Docker 的环境追加：首次部署、三角色登录、选课和计费、再次部署保留数据、停止后重启、日志检查与依赖服务故障恢复。本记录不把这些尚未执行的步骤计入通过项。
